# Alex — Purple Portfolio

Новое адаптивное портфолио в чёрно-фиолетовой гамме.

## Запуск

Откройте `index.html` в браузере или запустите через VS Code Live Server.

## Состав

- `index.html` — структура страницы
- `style.css` — дизайн, адаптивность и анимации
- `script.js` — мобильное меню, анимации появления, свечение курсора и копирование ссылки

## Перед публикацией

1. Проверьте ссылки на DETAIL PRO: они начнут работать после публикации этого проекта.
2. Замените ссылку на GitHub в блоке контактов на свой Telegram или email, если хотите получать обращения.
3. В репозитории `my-portfolio` замените старые `index.html`, `style.css`, `script.js` этими файлами, сохраните резервную копию старого проекта.
4. Выполните `git add .`, `git commit -m "Redesign portfolio in purple"`, `git push`.

Внешние библиотеки JavaScript не используются. Google Fonts подключаются через интернет, но сайт работает и без них благодаря запасным шрифтам.
